# ALFWorld 存储策略消融结果

评测日期：2026-10-09，Asia/Shanghai。本次配置下，全量存储的平均成功率更高，未复现原文“过滤更优”的方向。过滤减全量的原生 SR 差为 **-2.86 ± 2.47 个百分点**（三轮均值±样本标准差）。

完整数字与源码指纹见[结构化结果](alfworld_storage_ablation_2026-10-09.json)；协议、原论文Table9和复现边界见[消融规格](../storage_ablation.md)。

curator/executor 均为 API 配置模型 `gpt-5.5`，未训练 curator、未独立验证服务端权重。原论文的这项消融对应未训练Qwen3-8B curator的JITMEM-base；本实验模型与prompt改写不同，不能视为作者原模型或RL-trained结果的等价复跑。

两组固定完整valid_seen140任务、seeds0/1/2、batch10、workers10（spawn）、history3、max30 decisions、描述BM25 top3、每轮空库和无warm start。只有store_policy与对应curator标签展示不同；源码、采样配置、游戏、环境版本、任务顺序一致。judge仅观察任务与轨迹；native verifier只用于评分。

质量过滤组保留judge判成功的raw轨迹，不展示显式标签；全量组保存所有raw轨迹，检索时向curator展示executor judge的success/failure标签。executor只接收curator payload。整批完成后按预定任务顺序追加记忆。

评测pipeline源码与安全加固提交 `b04496576d8d0f3e144769fa7b2c47a2dfcc6b8e` 一致；本次重新运行两组，不混用旧版过滤结果。
